SOS-ESTOQUE — ENTREGA N2 — GRUPO 8

Integrantes: Guilherme Costa e Pedro Lucas Borges

Conteúdo:
- Java_Orientado_a_Objetos: aplicação web em Java 17, Spring Boot e Thymeleaf.
- Python_Procedural: aplicação de terminal em Python 3.10 ou superior.
- Documentacao: relatório N1 atualizado em DOCX e PDF.

Execução do Java:
1. Abra um terminal na pasta Java_Orientado_a_Objetos.
2. Execute: mvn spring-boot:run
3. Acesse: http://localhost:8080
4. Testes: mvn test

Execução do Python:
1. Abra um terminal na pasta Python_Procedural.
2. No Windows, execute: python main.py
3. Testes: python -m unittest -v

Observação:
Os dados ficam em memória nas duas versões e são apagados ao encerrar a aplicação.
